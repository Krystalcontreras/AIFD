Customizable Global City Comic Poster Generator

Overview

This skill guides the generation of posters blending mid-century comic/animation aesthetics with rigorous 1970s Swiss typographic layouts, eye-test chart grids, and responsive composition modes.

Core Design Rules

Masthead Style: Use a bold, playful display header with flexible positioning (Header Top, Center Stage, Side Vertical, Corner Accent, Footer Anchor) and responsive text scaling.
Eye-Test Grid Integration: Incorporate a vertical progressive scale element where text blocks step down in size row-by-row (from heavy bold sans-serif capitals at the top to fine-print typography at the bottom).
Color Palette:
Background: Acid chartreuse/lime green or high-contrast retro primaries with custom color pickers.
Accents: Saturated reds, deep blacks, mustard yellows, and cyan blues.
Illustration & Framing: Apply expressive landmark asset integration (such as city skylines for New York, Tokyo, London, Sydney, and Paris), flat block shading, bold black line art, and dynamic QR code map hubs.
Workflow Steps

Define Poster Theme & Title: Establish the central headline text and target city/editorial theme.
Establish Layout Grid: Set up a Swiss asymmetric grid balancing focal points with structured typographic columns across multiple layout modes.
Generate Typography Hierarchy: Apply high-contrast geometric sans-serifs for eye-test elements, paired with custom bouncy display faces for titles.
Apply Color & Export: Render with flat retro color blocks and export clean PNG outputs via html2canvas with local base64 asset support.

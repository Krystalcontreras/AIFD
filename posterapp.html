# Customizable Global City Comic Poster Generator

## Core Design Rules
1. **Masthead Style:** Bold display header with flexible positioning (Header Top, Center Stage, Side Vertical, Corner Accent, Footer Anchor).
2. **Eye-Test Grid Integration:** Vertical progressive scale element stepping down size row-by-row.
3. **Color Palette:** Acid chartreuse/lime green or high-contrast retro primaries with custom color pickers.
4. **Illustration & Framing:** Landmark asset integration (New York, Tokyo, London, Sydney, Paris), bold black line art, and dynamic QR code map hubs.

# Project Handoff: Global City Poster Generator

## Accomplishments
1. **Feature Expansion:** Converted generator into Global City Comic Poster Generator supporting multiple cities (New York, Tokyo, London, Sydney, Paris).
2. **Intentional Layout Modes:** Implemented 5 distinct layout composition modes preventing overlaps.
3. **Robust Local Export Fix:** Integrated automatic Base64 local image converter with html2canvas for seamless downloads under `file://`.
4. **Interactive Controls:** Added custom color pickers, font selectors, live QR code generation via qrcode.js, and auto-randomizer.

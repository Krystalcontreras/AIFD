1. Build the homepage as a single-page class portfolio/index that displays assignment links and a hero image at the top.

2. Use the hero image as a full-width banner that spans the entire viewport width from edge to edge with no side margins.

3. Place the user's name centered both horizontally and vertically within the hero image.

4. Use DM Serif Display for all headings.

5. Use Cormorant Garamond for all body text, link text, descriptions, and supporting content.

6. Headings must be visually dominant:
   - Hero title: 5rem desktop, 3rem mobile
   - Section headings: 2.5rem desktop, 2rem mobile
   - Font weight should remain elegant rather than bold-heavy.

7. Use the following color palette exactly:
   - Background: #FFFAFA
   - Text: #FFDAE9
   - Accent: #FAE6FA

8. Apply the accent color (#FAE6FA) to:
   - Link outlines
   - Button fills when appropriate
   - Decorative borders
   - Section dividers
   - Hover accents
   - Subtle background highlights behind featured content

9. The site aesthetic should combine:
   - SAMO ONDOH editorial minimalism
   - Rhode Skin softness and polish
   - Clean fashion-inspired presentation
   - Minimal but distinctive visual personality

10. Maintain generous white space, but ensure pages never feel empty. Content blocks should be balanced across the layout.

11. Use a three-column layout on laptops and desktop screens.

12. Use a single-column layout on phones.

13. Responsive breakpoints:
   - Mobile: under 768px
   - Tablet: 768px to 1023px
   - Desktop: 1024px and above

14. Desktop content container:
   - Max width: 1400px
   - Horizontal padding: 48px
   - Vertical section spacing: 96px

15. Mobile content container:
   - Horizontal padding: 20px
   - Vertical section spacing: 56px

16. Assignment links must appear as outlined buttons.

17. Assignment buttons must have:
   - Square corners (0px border radius)
   - 2px accent-colored border
   - Transparent background by default
   - Consistent sizing across the page

18. On hover, assignment links must become underlined.

19. Hover effects should be subtle and refined rather than dramatic.

20. Include a custom cursor experience inspired by the SAMO ONDOH character cursor concept:
   - Use a small branded decorative cursor element
   - Cursor motion should be smooth
   - Cursor effect must never interfere with usability

21. Include a Rhode-inspired scaling logo behavior:
   - A logo or name mark appears near the bottom portion of the initial viewport
   - When scrolling down, it gradually scales smaller
   - When scrolling upward or returning to the top, it scales larger again
   - Animation must be smooth and unobtrusive

22. Add a slow-moving background color shift throughout the page.

23. Background animation requirements:
   - Use tones derived from #FFFAFA and #FAE6FA
   - Duration: approximately 20 to 30 seconds per cycle
   - Infinite looping
   - Gentle transitions without abrupt changes

24. Use large imagery throughout the design style whenever secondary images are added.

25. Keep paragraph widths readable:
   - Maximum 70 characters per line
   - Line height between 1.6 and 1.8

26. Grid spacing:
   - 32px gaps between desktop columns
   - 20px gaps between mobile items

27. Use thin, elegant borders rather than heavy outlines whenever borders appear.

28. Avoid glassmorphism, heavy shadows, excessive gradients, neon effects, and cluttered decorative elements.

29. Visual hierarchy should prioritize:
   1. Hero image
   2. User name
   3. Assignment links
   4. Supporting text

30. The overall experience must feel polished, editorial, minimal, fashionable, calm, and modern while remaining clearly personal and creative.
